# Keyboard shortcuts

On macOS, use ⌘ where it says Ctrl.

## Everywhere

| Keys | Action |
|---|---|
| Ctrl+K | Jump to search |

## Open note

| Keys | Action |
|---|---|
| E | Switch from reading to editing |
| Ctrl+S | Save now (notes also save while you type) |
| Esc | Close the note (only while not editing) |
| Back (browser or phone) | Close the note |

## Text notes

The usual rich-text shortcuts: Ctrl+B bold, Ctrl+I italic, Ctrl+U underline, Ctrl+K add a link, Ctrl+Z / Ctrl+Shift+Z undo and redo. Markdown-style typing works too: `# ` for a heading, `- ` for a bullet list, `1. ` for a numbered list, `> ` for a quote.

## Checklists

| Keys | Action |
|---|---|
| Enter | New item below (splits the text at the cursor). On an empty sub-item: move it one level out. |
| Ctrl+Enter | Tick the item off, or back on |
| Tab / Shift+Tab | Make it a sub-item / move it one level out |
| Backspace at the start | Move one level out; at the top level, join with the item above |
| Delete at the end | Join the next item onto this one |
| Alt+↑ / Alt+↓ | Move the item (with its sub-items) up or down |
| ↑ / ↓ at the first or last line | Go to the previous or next item |

## Mind maps

With a topic selected:

| Keys | Action |
|---|---|
| Arrow keys | Move between topics |
| Tab or Insert | Add a subtopic |
| Enter | Add a sibling topic |
| Any letter | Start typing a new text for the topic |
| F2 | Edit the topic's text |
| Space | Fold or unfold the branch |
| Delete or Backspace | Remove the topic and its branch |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |

While editing a topic's text:

| Keys | Action |
|---|---|
| Enter | Done |
| Shift+Enter | New line |
| Tab / Shift+Tab | Done, and add a subtopic / sibling |
| Esc | Cancel |
